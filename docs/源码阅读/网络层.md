# 1. 集群类节点间通信

## 1.1 网络模块设计的asio异步操作有

`io_service_.post()`,`io_service_.run()`,`io_service_.stop()`,`async_wait()`,`async_write()`,`async_read()`,`async_accept()`

`boost::asio::async_write` 是 Boost.Asio 提供的一个异步写操作，用于将数据从应用程序的缓冲区写入到一个套接字（或其他支持异步写操作的对象）中。它的使用遵循异步 I/O 模式

```C++
template<typename AsyncWriteStream, typename ConstBufferSequence, typename WriteHandler>
void async_write(AsyncWriteStream &s, const ConstBufferSequence &buffers, WriteHandler &&handler);
```

`AsyncWriteStream &s`：要写入的流，必须支持异步写操作

`ConstBufferSequence &buffers`：待写入的数据缓冲区，使用boost::asio::buffer创建

`WriteHandler &&handler`写操作完成后的回调函数，如`void(const boost::system::error_code& error, std::size_t bytes_transferred);`

## 1.2 结构分析

### 1.2.1 AsioServer+ServerSession

> 在AsioServer的start函数中直接传递给ServerSession，AsioServer负责服务器的监听和接收客户端连接，同时通过回调函数接收来自ServerSession的消息。`ServerSession 负责`处理每个客户端连接的具体通信细节，包括读取消息头、消息体，并对消息进行解码，在处理完消息后，它通过回调函数将消息传递给 AsioServer。

共有两个类`ServerSession`和`AsioServer`

其中，`AsioServer`负责启动和关闭TCP服务端，即绑定、监听、接收客户端连接请求都在这里实现，而`ServerSession`负责处理tcp连接的读写事件

```c++
class AsioServer;
class ServerSession : public std::enable_shared_from_this<ServerSession> {
public:
    //构造函数初始化套接字和服务器指针
    explicit ServerSession(boost::asio::io_service &io_service, AsioServer *server)
        : socket(io_service), server_(server) {}
    //异步读取消息元数据
    void start_read_meta() {
        //确保meta_结构的大小是5字节
        assert(sizeof(meta_) == 5);
        meta_.type = 0;
        meta_.len = 0;
        //调用shared_from_this();可以在类的成员函数中安全地创建指向自身的共享指针
        auto self = shared_from_this();
        //将meta_结构的地址和大小封装成一个Boost.Asio缓冲对象，用于异步读取操作
        auto buffer = boost::asio::buffer(&meta_, sizeof(meta_));
        auto handler = [self](const boost::system::error_code &error, std::size_t bytes) {
            //读取字节数为0，表示连接已关闭，字节返回
            if (bytes == 0) {
                return;
                ;
            }
            //出现错误，返回
            if (error) {
                LOG_DEBUG("read error %s", error.message().c_str());
                return;
            }
            //读取的字节数不等于元数据的大小，记录错误并返回
            if (bytes != sizeof(meta_)) {
                LOG_DEBUG("invalid data len %lu", bytes);
                return;
            }
            //读取实际的消息内容
            self->start_read_message();
        };
        //从socket读取sizeof(meta_)字节数据到buffer并在完成时调用handler处理
        boost::asio::async_read(socket, buffer, boost::asio::transfer_exactly(sizeof(meta_)),
                                handler);
    }
    //根据元数据中指定的长度开始异步读取消息内容。如果缓冲区容量不足，则调整大小。
    //读取结束后调用`decode_message`函数解码消息
    void start_read_message() {
        //获取meta_消息的长度，ntohl函数用于将网络字节序转换为主机字节序
        uint32_t len = ntohl(meta_.len);
        //缓冲区容量小于消息长度，调整缓冲区大小适应即将读取的消息
        if (buffer_.capacity() < len) {
            buffer_.resize(len);
        }

        auto self = shared_from_this();
        //将buffer_的地址和长度封装成一个Boost.Asio缓冲区对象
        auto buffer = boost::asio::buffer(buffer_.data(), len);
        auto handler = [self, len](const boost::system::error_code &error, std::size_t bytes) {
            assert(len == ntohl(self->meta_.len));
            //读取错误或读取字节数为0
            if (error || bytes == 0) {
                LOG_DEBUG("read error %s", error.message().c_str());
                return;
            }
            //读取的字节数不等于消息长度
            if (bytes != len) {
                LOG_DEBUG("invalid data len %lu, %u", bytes, len);
                return;
            }
            self->decode_message(len);
        };
        //这行代码启动一个异步读取操作，从socket中读取len字节的数据到buffer，并在读取完成时调用handler处理。
        boost::asio::async_read(socket, buffer, boost::asio::transfer_exactly(len), handler);
    }

    void decode_message(uint32_t len) {
        switch (meta_.type) {
            case TransportTypeDebug: {
                //确保消息长度等于DebugMessage结构的大小
                assert(len == sizeof(DebugMessage));
                DebugMessage *dbg = (DebugMessage *)buffer_.data();
                //a,b满足某种关系
                assert(dbg->a + 1 == dbg->b);
                //LOG_DEBUG("tick ok");
                break;
            }
            case TransportTypeStream: {
                proto::MessagePtr msg(new proto::Message());
                try {
                    //msgpack::unpack将缓冲区的二进制数据解码为msgpack::object_handle对象
                    //并转换为proto::Message类型
                    msgpack::object_handle oh = msgpack::unpack((const char *)buffer_.data(), len);
                    oh.get().convert(*msg);
                } catch (std::exception &e) {
                    LOG_ERROR("bad message %s, size = %lu, type %s", e.what(), buffer_.size(),
                              proto::msg_type_to_string(msg->type));
                    return;
                }
                //处理解码后的消息
                on_receive_stream_message(std::move(msg));
                break;
            }
            //未知消息类型
            default: {
                LOG_DEBUG("unknown msg type %d, len = %d", meta_.type, ntohl(meta_.len));
                return;
            }
        }
        //处理完后调用该函数继续读取下一个消息元数据
        start_read_meta();
    }

    void on_receive_stream_message(proto::MessagePtr msg);

    boost::asio::ip::tcp::socket socket; //TCP套接字，用于与客户端通信

private:
    AsioServer *server_;          //指向服务器的指针，便于会话与服务器交互
    TransportMeta meta_;          //存储消息的元数据
    std::vector<uint8_t> buffer_; //一个字节缓冲区，用于存储从客户端读取的数据
};
typedef std::shared_ptr<ServerSession> ServerSessionPtr;
```



```C++
class AsioServer : public IoServer {
public:
    explicit AsioServer(boost::asio::io_service &io_service, const std::string &host,
                        RaftServer *raft)
        : io_service_(io_service), acceptor_(io_service), raft_(raft) {
        std::vector<std::string> strs;
        //使用boost::split函数将host字符串按“：”分割成IP地址和端口号
        //如果分割后得到的字符串数量不是2，则认为host无效
        boost::split(strs, host, boost::is_any_of(":"));
        if (strs.size() != 2) {
            LOG_DEBUG("invalid host %s", host.c_str());
            exit(0);
        }
        //将IP地址字符串转换为boost::asio::ip::address对象
        auto address = boost::asio::ip::address::from_string(strs[0]);
        //将端口号转换为整数
        int port = std::atoi(strs[1].c_str());
        //表示一个TCP连接的端点
        auto endpoint = boost::asio::ip::tcp::endpoint(address, port);
        //打开接收器并指定协议（TCP）
        acceptor_.open(endpoint.protocol());
        //设置接收器选项，允许地址重用。对于快速重启服务器非常有用
        acceptor_.set_option(boost::asio::ip::tcp::acceptor::reuse_address(1));
        //将接收器绑定到指定的端口
        acceptor_.bind(endpoint);
        //使接收器进入监听模式，准备接受传入的连接
        acceptor_.listen();
        LOG_DEBUG("listen at %s:%d", address.to_string().c_str(), port);
    }

    ~AsioServer() {}
    //定义为final，表示不能被子类重写
    void start() final {
        //创建一个新的ServerSession对象的共享指针
        ServerSessionPtr session(new ServerSession(io_service_, this));
        //异步接受传入连接并将连接关联到session->socket
        acceptor_.async_accept(session->socket,
                               [this, session](const boost::system::error_code &error) {
                                   if (error) {
                                       LOG_DEBUG("accept error %s", error.message().c_str());
                                       return;
                                   }
                                   //递归调用start，以便接受下一个连接，确保服务器始终在接受新的连接
                                   this->start();
                                   //启动读取元数据的异步操作
                                   session->start_read_meta();
                               });
    }

    void stop() final {}

    void on_message(proto::MessagePtr msg) {
        //process 方法的第二个参数是一个 lambda 函数，作为回调函数，当消息处理完成后被调用。这个回调函数接收一个 Status 对象作为参数。
        raft_->process(std::move(msg), [](const Status &status) {
            if (!status.is_ok()) {
                LOG_ERROR("process error %s", status.to_string().c_str());
            }
        });
    }

private:
    boost::asio::io_service &io_service_;
    boost::asio::ip::tcp::acceptor acceptor_;
    RaftServer *raft_;
};

void ServerSession::on_receive_stream_message(proto::MessagePtr msg) {
    server_->on_message(std::move(msg));
}
//该函数首先创建一个 AsioServer 的实例，然后将其转换为 IoServer 类型的共享指针并返回
std::shared_ptr<IoServer> IoServer::create(void *io_service, const std::string &host,
                                           RaftServer *raft) {
    std::shared_ptr<AsioServer> server(
        new AsioServer(*(boost::asio::io_service *)io_service, host, raft));
    return server;
}
```

在RaftNode的main函数中实例化了节点后，实例化每个节点的TransportImpl传输层，并调用对应的start函数，创建AsioServer实例，并调用对应的start启动

void RaftNode::process(proto::MessagePtr msg, const StatusCallback &callback) {
    if (pthread_id_ != pthread_self()) {
        io_service_.post([this, msg, callback]() {
            Status status = this->node_->step(msg);
            callback(status);
            pull_ready_events();
        });
    } else {
        Status status = this->node_->step(msg);
        callback(status);
        pull_ready_events();

## 2.1 RaftNode最上层类

RaftNode中的main函数

```C++
/// @brief 启动RaftNode节点，并设置节点间的通信
/// @param id 当前节点ID
/// @param cluster 集群配置，包含所有节点的地址
/// @param port 当前节点监听的端口
void RaftNode::main(uint64_t id, const std::string &cluster, uint16_t port) {
    ::signal(SIGINT, on_signal);
    ::signal(SIGHUP, on_signal);
    //创建RaftNode实例并赋值给g_node
    g_node = std::make_shared<RaftNode>(id, cluster, port);
    //创建传输层实例
    g_node->transport_ = Transport::create(g_node.get(), g_node->id_);
    //获取当前节点的地址 host
    std::string &host = g_node->peers_[id - 1];
    //调用start方法启动传输层
    g_node->transport_->start(host);
    //添加集群中其他节点
    for (uint64_t i = 0; i < g_node->peers_.size(); ++i) {
        uint64_t peer = i + 1;
        if (peer == g_node->id_) {
            continue;
        }
        g_node->transport_->add_peer(peer, g_node->peers_[i]);
    }
    //调度节点
    g_node->schedule();
}
```

在main函数中，创建了RaftNode节点实例，创建传输层实例，并启动传输层，并在addPeer方法中启动了PeerImpl

void RedisStore::start(std::promise<pthread_t> &promise) {

```C++
//用于开始接收新的客户端连接
void RedisStore::start_accept() {
    //用于创建一个新的RedisSession对象，用于处理新的客户端连接
    RedisSessionPtr session(new RedisSession(this, io_service_));
    //设置异步接受操作，当有新的连接到达时调用提供的回调函数
    acceptor_.async_accept(session->socket_,
                           [this, session](const boost::system::error_code &error) {
                               if (error) {
                                   LOG_DEBUG("accept error %s", error.message().c_str());
                                   return;
                               }
                               //没有错误则接收下一个连接，并调用session->start()处理当前连接
                               this->start_accept();
                               session->start();
                           });
}
```

服务器启动时，start_accept被首次调用，启动异步接受客户端连接的循环。`acceptor_.async_accept` 是一个异步操作，不会阻塞主线程。它会挂起当前操作，直到有新的客户端连接请求到达。

当有新的客户端连接到达时，Boost.Asio 会调用提供的回调函数：

* 如果发生错误，记录错误信息并返回
* 没有错误，调用session->start开始处理该连接，并立即调用start_accept接受下一个连接

在handle_read中处理收到的消息，并调用on_redis_reply处理解析出的Redis协议回复，并根据回复内容执行相应的命令回调，如`set_command,del_command`。调用redis_store对应的set方法

```C++
//设置一个键值对并通过raft协议进行提交，同时支持异步回调函数通知提交结果
void RedisStore::set(std::string key, std::string value, const StatusCallback &callback) {
    //生成一个唯一的提交id
    uint32_t commit_id = next_request_id_++;
    //构建raft提交对象
    RaftCommit commit;
    commit.node_id = static_cast<uint32_t>(server_->node_id());
    commit.commit_id = commit_id;
    commit.redis_data.type = RedisCommitData::kCommitSet;
    commit.redis_data.strs.push_back(std::move(key));
    commit.redis_data.strs.push_back(std::move(value));
    //序列化提交对象
    msgpack::sbuffer sbuf;
    msgpack::pack(sbuf, commit);
    std::shared_ptr<std::vector<uint8_t>> data(
        new std::vector<uint8_t>(sbuf.data(), sbuf.data() + sbuf.size()));
    //将回调函数保存到pending_requests_映射中，使用提交ID作为键
    pending_requests_[commit_id] = callback;
    //提交数据到raft节点
    //server_是RaftNode
    server_->propose(std::move(data), [this, commit_id](const Status &status) {
        //处理提交结果，使用io_service_.post将结果处理函数添加到IO服务的事件队列中
        io_service_.post([this, status, commit_id]() {
            if (status.is_ok()) {
                return;
            }
            //在结果处理函数中，如果提交失败，调用保存的回调函数，并从pending_request_中移除对应条目
            auto it = pending_requests_.find(commit_id);
            if (it != pending_requests_.end()) {
                it->second(status);
                pending_requests_.erase(it);
            }
        });
    });
}
```

RaftNode的propose方法

```C++
/// @brief 将提案提交给raft节点
/// @param data 提案的数据，以字节数组的形式存储
/// @param callback 提案提交后的回调函数，用于返回提交状态
void RaftNode::propose(std::shared_ptr<std::vector<uint8_t>> data, const StatusCallback &callback) {
    //当前线程与存储的线程ID不匹配，使用io_service_.post将任务提交到IO服务线程中执行
    if (pthread_id_ != pthread_self()) {
        io_service_.post([this, data, callback]() {
            Status status = node_->propose(std::move(*data));
            callback(status);
            pull_ready_events();
        });
    } else {
        Status status = node_->propose(std::move(*data));
        callback(status);
        pull_ready_events();
    }
}
```

leader会进行广播，日志条目将被发送到各个节点中，这个过程中会有两阶段提交(2PC)，当日志条目被大多数节点复制后，ledaer会将日志条目存储到数据库中，最后在通知各节点也将日志条目存储到数据库。
